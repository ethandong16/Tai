# Changelog

## v1.1.0 - 2026-09-22

- Redesigned the WinUI interface with responsive navigation, updated surfaces, and refined light and dark themes.
- Added native category distribution and interactive usage trend charts.
- Added record search and preserved application or website filters when opening the full details view.
- Updated project, discussion, release, and browser extension links to the maintained fork.

## v1.0.0 - 2026-09-18

First formal release of the Tai WinUI 3 edition.

- WinUI 3 is the maintained desktop interface.
- Added application usage dashboards, statistics, details, categories, and settings views.
- Added Chromium website usage tracking through the companion extension.
- Added local-only data handling and browser extension usage guidance.
- Added self-contained `win-x64` release packaging and GitHub Actions release automation.
- Removed legacy WPF, updater, and crash-handler projects from the maintained solution.
