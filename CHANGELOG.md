# Changelog

## v1.0.0 - 2026-09-18

First formal release of the Tai WinUI 3 edition.

- WinUI 3 is the maintained desktop interface.
- Added application usage dashboards, statistics, details, categories, and settings views.
- Added Chromium website usage tracking through the companion extension.
- Added local-only data handling and browser extension privacy documentation.
- Added self-contained `win-x64` release packaging and GitHub Actions release automation.
- Removed legacy WPF, updater, and crash-handler projects from the maintained solution.
